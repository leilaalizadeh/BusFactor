How it works

One loop, run on the team's own project file. Every step is saved and shown in an action log.

  1. Find the decisions

    Five key decisions are pulled from the report, each with a quote checked against its page.

  2. Ask privately

    Each member answers "why" and "what if" questions about parts they didn't build. Scores 0 to 2, seen only by them.

  3. Spot the risk

    A decision only one person can explain is a single point of failure.

  4. Teach each other

    Someone who understands it teaches someone who doesn't, if both agree.

  5. Check again

    The learner gets a new question with no hints. A score of 2 raises team coverage.

Rules enforced in the code

These hold even if the AI model gets something wrong. Each one has an automated test.

  • No invented sourcesA decision without a quote on its cited page is never assessed.
  • Answers stay privateMembers see only their own answers. The team view shows counts, never names or scores.
  • Both people agreeA teaching session starts only when mentor and learner both accept.
  • No pretend mentorsIf nobody can explain a decision, BusFactor points to the course material or the TA.
  • No answers in the retest"Just give me the answer" is refused, in English or Italian.
  • Coverage moves on evidence onlyIt goes up only when a learner scores 2 on a new question.
